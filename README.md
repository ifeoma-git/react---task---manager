# React Task Manager

A simple task manager application built with React.

## Features
- Add tasks
- Delete tasks
- Dynamic task list using React state

## Technologies
- React
- JavaScript
- HTML
- CSS

## Run the Project

Clone the repository:

git clone https://github.com/ifeoma-git/react---task---manager.git

Install dependencies:

npm install

Start the application:

npm start

The app runs at:
http://localhost:3000
